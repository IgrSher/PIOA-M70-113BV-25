Проект предствляет из себя простую систему управления базой данных, поддерживающую работу с несколькоими пользовательскими таблицами с базовыми операциями CRUD.
Струткура проекта:
```
src/
│
├── db/
│   ├── __main__.py          # точка входа 
│   ├── backend/
│   │   ├── memory.py        # in-memory хранилище и логика БД
│   │   ├── errors.py        # кастомные исключения
│   ├── tui.py               # текстовый интерфейс (
│
├── tests/
    ├── test_memory.py           # тесты backend логики
    └── test_tui.py              # тесты интерфейса
```

Основные используемые классы
1. MemoryDB (backend/memory.py)
    Ядро системы хранения данных.
    
    Отвечает за:
    создание таблиц,
    хранение записей,
    CRUD операции,
    поиск и фильтрацию записей.


2. TUI (tui.py)
    Консольный интерфейс пользователя.

    Отвечает за:
    меню приложения,
    обработку пользовательского ввода,
    вызовы методов, 
    валидацию ввода.

Запуск проекта производится из корневой директивы командой ```py -m src.db``` либо ```python -m src.db```
Проверка на покрытие тестами проекта осуществляется также в корневой директиве командой ```py -m pytest --cov=src --cov-report=term-missing```
