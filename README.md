Описание
Простая консольная система управления данными, модель базы данных в оперативной памяти.
Поддерживается работа с несколькими таблицами и базовые операции CRUD.

Структура
src/db
│
├── backend/
│   ├── memory.py - хранение данных и операции с таблицами
│
│   ├── tui.py    - консольный пользовательский интерфейс 
│   ├── __main__.py   - точка входа, запуск программы

Функциональность:

Работа с несколькими таблицами
Добавление записей
Выбор и просмотр данных
Поиск по полям
Обновление записей
Удаление записей

Запуск проекта производится через консоль, в директории проекта src необходимо ввести команду "python -m db" или "py -m db"
