# База данных на Python

## Описание проекта

Проект представляет собой простую базу данных, разработанную на Python с использованием объектно-ориентированного программирования.

База данных позволяет создавать таблицы, добавлять, просматривать, изменять и удалять записи. Поддерживаются два варианта хранения данных:
- В оперативной памяти, данные хранятся во время работы программы.
- В JSON-файле, данные сохраняются на диске и загружаются при повторном запуске.

Для взаимодействия с базой данных реализован текстовый пользовательский интерфейс.

## Возможности

- Создание таблиц с заданными полями и типами данных.
- Добавление новых записей.
- Просмотр записей с возможностью фильтрации.
- Изменение существующих записей.
- Удаление записей.
- Проверка типов и корректности данных.
- Проверка уникальности идентификаторов записей (`id`).
- Обработка ошибок при работе с таблицами и записями.
- Сохранение и загрузка данных в формате JSON.
- Автоматическое создание файла базы данных при первом сохранении.

## Структура проекта

```
src/
└── db/
    ├── __main__.py
    ├── tui.py
    └── backend/
        ├── memory.py
        ├── file.py
        └── errors.py

tests/
├── test_memory.py
├── test_file.py
└── test_tui.py
```

### Основные модули

- `memory.py` — реализация базы данных в оперативной памяти, работа с таблицами и записями.
- `file.py` — реализация базы данных с сохранением данных в JSON-файл.
- `errors.py` — пользовательские исключения для обработки ошибок.
- `tui.py` — текстовый интерфейс для взаимодействия с базой данных.
- `__main__.py` — точка входа в приложение.
- `tests/` — автоматические тесты для проверки работы программы.

## Требования

Для запуска необходимы:
- Python 3.10 или новее.
- `pytest` и `pytest-cov` для запуска тестов.

Основная функциональность реализована с использованием стандартной библиотеки Python.

## Запуск программы

Откройте терминал в корневой папке проекта и выполните команду:

```
py -m src.db
```

При запуске используется файловая база данных. По умолчанию данные сохраняются в файле `database.json`.

При первом запуске файл может отсутствовать — он будет создан при первом сохранении изменений.

## Формат хранения данных

Данные сохраняются в JSON-файле. Для каждой таблицы хранятся описание столбцов и список записей.

Поле `id` используется как уникальный идентификатор записи. Типы полей задаются при создании таблицы.

## Запуск тестов

Для запуска всех тестов с измерением покрытия кода выполните:

```bash
py -m pytest --cov=src --
```

Тесты проверяют основные операции с таблицами и записями, сохранение данных, загрузку из файла, работу пользовательского интерфейса и обработку ошибок.

## Обработка ошибок

При некорректных операциях программа использует специальные исключения. В частности, обрабатываются ситуации, когда:
- таблица уже существует;
- таблица или запись не найдена;
- идентификатор некорректен или повторяется;
- данные не соответствуют заданной схеме;
- файл базы данных содержит некорректный JSON или имеет неправильную структуру;
- чтение или сохранение файла завершается ошибкой.
